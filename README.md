# Today with Chandra — mirror feed

This is a corrected mirror of the "Today with Chandra" podcast RSS feed.
It contains the same episodes as the original feed, with the Author and
contact-email fields added so the show can be listed in podcast
directories (e.g. Spotify for Creators) that require them.

- Feed: `feed.xml` (served via jsDelivr)
- Cover: `cover.jpg`

The feed is regenerated automatically after each new episode is published.
Audio files themselves are still hosted on the original feed's media URLs.
